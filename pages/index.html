Frontend Development

A collection of notes covering the essential technologies used to build modern, responsive, and interactive websites.

01

HTML

HyperText Markup Language

HTML is the standard markup language used to structure webpages. It provides the foundation of a website by organizing headings, paragraphs, images, links, buttons, forms, and other elements.

Important Concepts

HTML document structure
Headings & paragraphs
Links & images
Lists
HTML attributes
Forms & inputs
Semantic HTML
Tables
HTML comments

Example

<h1>Welcome to My Website</h1>
<p>This is a paragraph.</p>
<a href="#">Learn More</a>
02

CSS

Cascading Style Sheets

CSS controls how HTML elements look on a webpage. It is used for colors, typography, spacing, layouts, positioning, animations, responsive designs, and visual effects.

Important Concepts

CSS selectors
Colors & backgrounds
Typography
Margin & padding
Flexbox
CSS Grid
Positioning
Media queries
Animations

Example

h1 {
  color: red;
  font-size: 32px;
  text-align: center;
}
03

Tailwind CSS

Utility-First CSS Framework

Tailwind CSS is a utility-first CSS framework that provides small, reusable utility classes for quickly building modern and responsive interfaces directly in HTML.

Important Concepts

Utility classes
Colors
Spacing
Flexbox & Grid
Responsive breakpoints
Width & height
Rounded corners
Hover & focus
Positioning

Example

<button class="bg-red-600 text-white px-6 py-3 rounded-full hover:bg-red-700">
  Click Me
</button>
04

SCSS

Sassy CSS

SCSS is a CSS preprocessor that extends CSS with features such as variables, nesting, mixins, functions, and reusable styles. SCSS is compiled into regular CSS that browsers can understand.

Important Concepts

Variables
Nesting
Mixins
Functions
Partials
Inheritance
Operators
Reusable styles
Compilation

Example

$primary-color: red;

.button {
  background-color: $primary-color;
  padding: 12px 24px;
  border-radius: 8px;

  &:hover {
    background-color: darkred;
  }
}
05

JavaScript

Programming Language for the Web

JavaScript is a programming language that makes websites interactive and dynamic. It can respond to user actions, manipulate HTML and CSS, validate forms, communicate with APIs, and build complete web applications.

Important Concepts

Variables
Data types
Operators
Conditions
Loops
Functions
Arrays & objects
DOM manipulation
Event listeners
Form validation
Async / Await
Fetch API

Example

const button = document.querySelector("button");

button.addEventListener("click", () => {
  alert("Button clicked!");
});
06

Frontend Development

Putting everything together

Frontend development combines different technologies to create complete user interfaces. Each technology has a different role, but they work together to create modern websites and web applications.

HTML

Creates the structure.

CSS

Controls the appearance.

Tailwind

Speeds up styling.

SCSS

Organizes advanced CSS.

JavaScript

Adds functionality.

About This Project

This project helps students practice HTML, Tailwind CSS, and JavaScript together in one simple application.

Topics Covered

  • HTML Structure
  • Tailwind CSS Styling
  • JavaScript Basics
  • DOM Manipulation
